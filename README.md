# EventBot

Discord サーバーのイベント（企画）を管理する Bot です。discord.py で動きます。

イベントの作成から開始・終了までを Discord 上で完結させ、VC にいた時間から参加者を自動で集計します。

## できること

- **イベントの作成**：日時・主催・VC・ゲームを指定して作成すると、Discord のイベントも同時に作られます
- **予定の一覧表示**：告知用の Embed をチャンネルに並べます。並び順は上から「終了・キャンセル済み → 開催予定 → 開催中」で、それぞれ日時順です
- **主催者への管理 DM**：当日 9:00 か開始 1 時間前の早いほうに、主催者へボタン付きの管理画面を DM で送ります
  - 開始前：開始 / 内容変更 / イベントキャンセル
  - 開催中：終了
- **開始のお知らせ**：ゲームごとのロールが設定されていれば、開始時にメンションします
- **参加者の集計**：開始から終了までに指定 VC にいた時間を合計し、10 秒以上いた人を長い順に表示します
- **変更・削除の承認制**：内容変更や削除は管理者連絡チャンネルに申請が届き、申請者本人以外の管理者が確認すると反映されます。拒否したときは理由が申請者に DM で届きます
- **サーバーごとの設定**：設定とデータはサーバーごとに分かれているので、複数のサーバーで使えます

## 必要なもの

- Python 3.11 以上
- discord.py 2.6 以上
- python-dotenv

## セットアップ

### 1. Bot を用意する

[Discord Developer Portal](https://discord.com/developers/applications) でアプリケーションを作り、Bot のトークンを取得します。

**Bot** タブで **SERVER MEMBERS INTENT** を ON にしてください（必須）。

### 2. サーバーに招待する

招待 URL には、次のスコープと権限を付けてください。

- **スコープ**：`bot`、`applications.commands`
- **権限**（整数：`17601045679104`）

| 権限 | 用途 |
|---|---|
| チャンネルを見る | チャンネルと VC の状態を確認する |
| メッセージを送信 / 埋め込みリンク | 告知・お知らせ・申請を送る |
| メッセージ履歴を読む | 告知 Embed を編集・並べ替える |
| @everyone・@here・すべてのロールにメンション | メンション不可のロールでも開始時に通知する |
| 接続 | VC で Discord イベントを作成する |
| イベントの作成 / イベントの管理 | Discord イベントを作成・開始・終了・キャンセルする |
| ロールの管理 | ロールパネル（テスト用）でロールを付け外しする |

告知用のチャンネルに低速モードをかける場合は、「低速モードを回避」も付けてください。

### 3. インストールと起動

```bash
git clone https://github.com/yuta25912/EventBot.git
cd EventBot
pip3 install -r requirements.txt
cp .env.sample .env
```

`.env` を開き、`DISCORD_TOKEN` にトークンを書いてから起動します。

```bash
python3 main.py
```

### 4. サーバーごとの初期設定

起動したら、各サーバーで次のコマンドを実行します。

| コマンド | 設定する内容 |
|---|---|
| `/admin config_admin_role` | 管理者ロール（未設定の間は、サーバーの管理者権限を持つ人が管理者になります） |
| `/admin config_admin_channel` | 管理者連絡チャンネル（申請やキャンセルの通知が届きます） |
| `/admin config_schedule_channel` | イベント予定チャンネル（告知 Embed を並べます） |
| `/admin config_event_channel` | イベントチャンネル（開始・終了のお知らせを送ります） |
| `/admin config_game_add` | ゲームと、開始時にメンションするロール（Minecraft は最初から登録済み） |
| `/admin config_show` | 今の設定を確認する |

## コマンド一覧

### 管理者用（`/admin`）

| コマンド | 説明 |
|---|---|
| `event_create` | イベントを作成する。入力画面で企画名・内容（Minecraft ならバージョンも）を入れ、確認してから作成する |
| `event_list` | 今後のイベントを一覧表示する。`すべて: True` で終了・キャンセル済みも出す |
| `event_delete` | イベントの削除を申請する（ほかの管理者の確認が必要） |
| `config_*` | 各種設定（上の表を参照） |
| `rolepanel` | ロールパネルを設置する（テスト用サーバーのみ） |

### 主催者用（`/host`）

主催者本人と管理者が使えます。

| コマンド | 説明 |
|---|---|
| `event_modify` | イベントの内容変更を申請する |
| `event_panel` | 管理画面を、このチャンネルか DM に表示する |

## 日時の入力

JST で、次の形式で入力します。入力中には候補も出ます。

- `2026-10-12 21:00`
- `10/12 21:00`（年を省略すると、今年か来年を自動で選びます）

## データの保存

データは `data/data_{サーバーID}.json` に、サーバーごとに保存されます。終了・キャンセル・削除したイベントの記録も残ります。

テスト用サーバーとして扱いたい場合は、そのサーバーのデータファイルで `config.test_server` を `true` にしてください。`/admin rolepanel` が使えるようになります。

## ディレクトリ構成

```
main.py              起動ファイル
event/
  actions.py         イベント操作の本体（作成・開始・終了・並べ替え・参加時間の計測）
  storage.py         サーバーごとのデータ保存
  embeds.py          Embed の組み立て
  timeutil.py        日時の入力・表示
  perms.py           権限チェック
  errors.py          エラーを操作した人に表示する
  cogs/
    commands.py      スラッシュコマンド
    background.py    定期処理・VC 入退室・Discord イベントとの同期
  views/
    editor.py        作成・編集画面
    panel.py         主催者向け管理画面
    approval.py      変更・削除の承認
    rolepanel.py     ロールパネル
```
